# DeepWiki Plugin UI/UX Refactoring Design

## Overview
This design document outlines the UI/UX refactoring and feature enhancements for the DeepWiki local repository plugin in Proma. The goal is to elevate it from a "demo" implementation to a polished, professional feature that leverages Proma's agent capabilities and Shadcn UI components.

## Core Features
1.  **Deep Repository Analysis:** Go beyond simple summaries to provide architectural insights, module dependencies, and capability clues.
2.  **Bilingual Support:** Allow users to choose between Chinese and English for the generated Wiki output.
3.  **Visualizations:** Use Mermaid diagrams to visualize architectures and dependencies within the generated Markdown.
4.  **Integrated Chat:** Maintain the ability to chat with the document knowledge base contextually.

## Layout & UX (Sidebar + Main Area)
The workbench will utilize a horizontal `split` layout to separate controls/status from the primary reading content.

### 1. Left Panel (Sidebar)
*   **Width:** Narrower (e.g., ratio 1).
*   **Components:**
    *   **Toolbar (`toolbar`):**
        *   Contains the "Analyze Repository" action.
        *   Uses Shadcn UI forms (`Input`, `Select`, `Button`).
        *   Core inputs (Repository Path, Model, Knowledge Base ID) are visible by default.
        *   Advanced settings (Language, Analysis Depth) are housed within a collapsible/foldable section to reduce initial visual clutter.
    *   **Task Status (`task-status`):**
        *   Displays the progress of the scanning and indexing task.
        *   Uses clean Shadcn UI progress bars and badges.
        *   Placed here to inform the user without obstructing the reading area.
    *   **Document Chat (`document-chat`):**
        *   Anchored at the bottom of the sidebar.
        *   Allows contextual Q&A based on the analyzed repository.
        *   Styled with Shadcn UI tokens for message bubbles and input.

### 2. Right Panel (Main Area)
*   **Width:** Wider (e.g., ratio 2.4).
*   **Components:**
    *   **Markdown Viewer (`markdown`):**
        *   The primary focus area, taking up the majority of the screen space.
        *   Uses the existing `MarkdownRenderer`.
        *   Will automatically render Mermaid code blocks (` ```mermaid `) generated by the AI as interactive diagrams, thanks to the `@proma/ui` `MermaidBlock` component.
        *   Empty state will be improved to guide the user (e.g., "Enter a repository path and click Analyze to generate the Wiki").

## Visual Polish & Styling (Shadcn UI)
The `PluginWorkbenchRenderer.tsx` will be reviewed and updated to ensure all rendered components (`panel`, `card`, `toolbar`, inputs, chat) strictly adhere to Shadcn UI conventions and design tokens:
*   **Backgrounds:** `bg-background`, `bg-card`, `bg-muted`.
*   **Text:** `text-foreground`, `text-muted-foreground`.
*   **Borders:** `border-border`.
*   **Interactive Elements:** Proper focus states (`focus-visible:ring-ring`), hover states, and variants (`default`, `secondary`, `outline`).

## Data Flow Updates
1.  **`ai-indexing-service.ts`:**
    *   Update `generateRepositorySummary` prompts to explicitly request Mermaid diagrams when `analysisDepth` is 'deep'.
    *   Ensure the prompts respect the selected `language`.
2.  **`PluginWorkbenchRenderer.tsx`:**
    *   Implement the collapsible UI for toolbar advanced settings.
    *   Apply Shadcn UI classes to all renderer branches.
